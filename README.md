# Course web development, week 3, assignment 1
It's a simple Express-server with API, which returns a JSON array of cat objects.

## Start

1. Verify the Node.js and npm versions:

Node.js:
```bash
node -v
```
npm:
```bash
npm -v
```

2. Install all dependencies:
```bash
npm install
```

Express:
```bash
npm install express
```

Nodemon:
```bash
npm install -D nodemon
```

3. Run the server

```bash
npm run dev
```

4. Open API in Chrome-browser: `http://localhost:3000/api/v1/cats`
Files from directory `public` is available by `http://localhost:3000/public/<file_name>`.

All checks for http-requests can be found: `../public/results/result<what kind of>`.
